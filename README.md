

# Vesuvio - Site Fictício para Restaurante

Este projeto é um site fictício desenvolvido para o restaurante Vesuvio, inspirado na série "The Sopranos". Foi criado como parte do curso "Profissão: Engenheiro Front-end - Ebac", com o intuito de praticar o uso do framework **Bootstrap**.

---

## 🔍 Visão Geral

- **Status**: Concluído
- **Tecnologias**: HTML, CSS, Bootstrap

---

## ⚙️ Funcionalidades

- **Menu Interativo**: Apresentação do cardápio do restaurante com opções de pratos e bebidas, permitindo uma navegação fácil e intuitiva.

- **Seção "Sobre Nós"**: Informações sobre a história do restaurante, sua filosofia e o que o torna especial, criando uma conexão com os visitantes.

- **Galeria de Imagens**: Exibição de fotos do ambiente e dos pratos, destacando a experiência gastronômica oferecida.
